## Checklist

- [ ] Los commits siguen la [guía de commits](../../commit-guide/COMMIT_GUIDE.md) del equipo (asunto 20–50 chars, `What:`, `Why:`, ticket al final).
- [ ] Concurrency, performance y edge cases revisados si aplica.
- [ ] Tests unitarios/integ. añadidos o actualizados cuando corresponda.
- [ ] Documentación actualizada cuando corresponde.
- [ ] El build y linter pasan localmente.
